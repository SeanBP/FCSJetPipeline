2. SIMULATION
-------------
Command (provenance/run_params_*.txt):
  submit_sim_to_jet.sh with label jes_pixring_v1, pythia6, PyTune 370,
  -M 1 (FMS tune), -w pthat_distribution_nofilt_em_only.json, 5000 jobs
  x 2000 events, -s 10 (SimpleTree of every 10th job kept), -e 0 (no
  generator filter), -E 1 (EM-only), -F 1 (jets from FCS points),
  -C 1 (calibration sample: no jet pT minimums), -K 0.947, no trigger
  filter, calib_run 0, random seeds (seed_base 0), MuDsts not kept.

Generator (sim_to_jet/starsim_pythia6_filter.C):
  Pythia 6.4.28, pp at sqrt(s) = 508.4 GeV (CMS frame), MSEL = 1 (hard QCD).
  "FMS tune", as the STAR FMS EM-jet analysis: PyTune 370 (Perugia 2012,
  PDF CTEQ6L1 through LHAPDF set 10042), then PARP(90) = 0.213,
  PARP(91) = 1.
  ptHat window per job from the allocation table below (CKIN(3), CKIN(4)).
  Particles passed to GEANT: 1 < eta < 5, all phi, all pT.
  Vertex: Gaussian, centre (0, 0, 0), widths 0.1, 0.1, 30 cm.
  FcsJetFilter added with threshold 0 GeV: no event is rejected.
  Geometry y2023 (starsim and BFC).
  Per-job random seed from /dev/urandom (mod 100000).

Reconstruction (sim_to_jet/runSimBfc.C, readMudst.C):
  BFC chain "y2023,AgML,USExgeom,fzin,geant,FieldOn,logger,MakeEvent,
  fcsSim,fcsWFF,fcsCluster,fcsPoint,cmudst", trigger version 202207.
  ECal deposited energy scaled by k = 0.947 before digitization
  (StFcsFastSimulatorMaker::setEcalScale).
  FCS gains: conditions DB at BFC's nominal date (calib_run 0).
  MuDst clusters seeded at 1 GeV ECal and HCal (as P24ia).
  readMudst.C (trgSelect 202209) reclusters as data: ECal towers
  >= 0.4 GeV, HCal 0.01 GeV, seeds 1 GeV; SimpleTree from the reclustered
  clusters and points. Trigger simulation from stage_params.txt (not used
  as a filter).

Jet finding (sim_to_jet/JetMatcher.cpp, "JetMatcher list '' 1 1 0"):
  anti-kT, R = 0.7, active areas (ghost area 0.04, |ghost y| < 5).
  Reco: FCS ECal points (det 0, 1) with 1 GeV < E <= sqrt(s)/2
  (sqrt(s) = 508.426 GeV); no jet pT minimum (calibration sample); jet
  axis at z = 721.5402 cm inside the ECal rectangle
  x 20.536-137.595 cm, y -96.724-86.256 cm, with a 20 cm inner buffer.
  Truth: photons made within 0.01 cm of the primary vertex (GEANT id 1),
  in the eta band of the reco fiducial region +- 1.5R; jets with pz > 0
  whose axis is within R/2 (eta-phi) of the reco fiducial region; no pT
  minimum.
  Matching: reco-truth pairs by increasing dR, one to one, dR < R/2.

Underlying event (underlying_event/, in the same job, per file):
  eta-weighted side wedges: the jet's eta band |deta| < R, from 2R off the
  jet axis to |dphi| = 150 deg, other jets kept, whole ECal, weighted per
  point so the area-per-eta matches the jet cone's (eta bins 0.05; bins
  covered below 10% of the jet's area get no weight); reco areas from 3 cm
  tiles with 3 x 3 sub-tiles. UE = density x jet cone area (live area at
  reco, pi R^2 at truth). Truth from the same truth photons, full azimuth.

4. JES POINTS (jet_scale/JetEnergyScaleFineGrid_em_only.cpp)
------------------------------------------------------------
Command: JetEnergyScaleFineGrid_em_only jes_pixring_v1/flat/ "" "" "" "" "" "" 50
Jets: all matched pairs of the 4929 files, 5,948,113, none dropped for a
missing UE estimate. Both energies UE subtracted:
  scale = (reco_E - reco_ue_E) / (truth_E - truth_ue_E),
binned in subtracted truth energy; each jet cross-section weighted.
Truth-energy bins: 20, 3-100 GeV, power-law edges (curvature 1.5); jets
outside dropped.
Position: reco jet |x|, y (north and south folded), grid points every
2.5 cm inside the ECal rectangle with the 20 cm buffer; a point pools jets
within 5 cm, 10 cm for bins from 37 GeV. At least 5 entries per point.
Estimator per point: Gaussian core (jet_scale/GaussCore.h, default
window) where n_eff >= 50 and the fit converges with chi2/ndf < 3 and
sigma/mean < 0.35; otherwise the kernel-density peak.
Result: core for 15178 points (of 18253 with n_eff >= 50), kernel peak for
18308; rejected core fits (scale and response counted separately): not
converged 326, chi2/ndf >= 3 779, sigma/mean >= 0.35 2431.
Output: jet_calibration.root (this folder).


5. MAP FIT (jet_scale/CalibrationMap_em_only.cpp)
-------------------------------------------------
Command: CalibrationMap_em_only jet_calibration.root JetEnergyScale_lookup_em_only.json
Model: scale(E) = A + B lnE + C ln^2 E + D ln^3 E, E the reco (response)
energy; C, D global, A, B per position. The order follows ATLAS
(arXiv:1112.6426, Eq. 9); removing D worsens chi2 by 956.
Points used: n_eff >= 3, response <= 1.5x and scale <= 1.5 sanity cuts,
at least 4 energy bins per position.
Global fit: 1798 positions, 33256 points, chi2/ndf = 65749.2/29658,
  C = 0.025095 +- 0.001136, D = -0.003018 +- 0.000145 (errors x 1.49),
  corr(C, D) = -0.993.
A, B smoothed as the scale at 3 and 30 GeV (6 iterations, radius 2),
masked to the buffered ECal fiducial region: 1798 of 3478 cells saved.
Evaluators clamp E to the fitted response range 1.29-96.78 GeV.
Applied as E_corr = E / scale(E) at the jet's |x|, y (bilinear in A, B).


6. CLOSURE (jet_scale/jes_closure.cpp)
--------------------------------------
Command: jes_closure closure_files.list JetEnergyScale_lookup_em_only.json ue jes_closure jet_calibration.root
Same 4929 files and UE-subtracted pairs, jets inside the map's fiducial
region. Central value of E_corr / E_truth per truth-energy bin: Gaussian core
where the bin's n_eff >= 250, otherwise kernel peak; bootstrap errors.
Output: jes_closure.txt / .root / .png (this folder).
